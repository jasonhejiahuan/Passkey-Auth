# Quick start

The supported server is the native Cloudflare Worker in `worker/`.

Follow [Cloudflare initialization](docs/cloudflare-native.md) for local development, new D1 initialization, administrator bootstrap, deployment and runtime limits. Follow [OAuth integration](docs/oauth-integration.md) for client contracts.

The Python desktop workflow is archived in [Legacy Python](docs/legacy-python.md); it is not a Cloudflare deployment path.
