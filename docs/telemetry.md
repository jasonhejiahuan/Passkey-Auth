# 可选浏览器遥测

遥测默认关闭，不参与 Passkey、OAuth 或权限判断。保留原 Management 控件、设备分布、统计、CSV、逐用户设置、内置／Jason／custom 后端及 relay／direct 发送方式。

## 关闭与隐私

普通页面和采集请求只读取一次 D1 中的权威 `telemetry_config`，同请求共享结果。关闭时不查询遥测事件／用户策略表，不读取或重写 HTML，不注入采集脚本，不发起浏览器或外部采集请求。旧的可选 `/api/telemetry/browser-token` 桥接也服从总开关。跨 Worker 实例不缓存开关，避免管理员关闭后其他实例继续收集。管理员主动打开 Management 时仍可查看和导出已有历史统计；关闭采集不会把历史记录伪装为零。

启用后，可分别选择匿名访客和每个用户的屏幕、硬件摘要、字体、电池、网络与显示偏好。用户策略为继承、关闭或自定义。原采集脚本在浏览器空闲时执行；字体模块按操作系统加载，电池能力只在启用且浏览器支持时调用。关闭的能力不会被保存在事件中。

页面路径去掉查询与 fragment，referrer 仅保留 origin。不会保存 Secret、Cookie、授权码或完整认证 Token。IP 采用每条事件不同的哈希，不提供跨事件固定 IP 指纹。字体数量及字段长度有上限。登录／管理审计仍独立记录必要的操作信息，不是浏览器遥测。

## 一次性与撤回

采集令牌为高熵不透明值，D1 只存哈希，有效期 300 秒，绑定用户、能力列表与当前策略。管理设置变更后，旧策略令牌即时失效。令牌消费、策略复核及事件插入在同一 D1 事务内完成，重复 beacon 不重复写入。

`POST /api/telemetry/collect` 最多 16 KiB；`POST /api/telemetry/direct-target` 最多 4 KiB。默认使用内置 D1 接收。普通页面不会为遥测等待额外 UI 步骤；Management 和恢复注册页面不注入采集器。

## 接收端

- **builtin**：事件保存在本项目 D1，可统计、导出和清除。
- **Jason**：保留一次性配对码 HMAC 双阶段握手、测试连接、服务端转发与浏览器短期目标。
- **custom**：公开 HTTPS POST 目标，支持服务端 Bearer／自定义 Header，以及无私密凭据的浏览器直连。

外部地址必须为公开 HTTPS 域名，不接受 URL 用户名密码、裸 IP、localhost／LAN／metadata 名称；不跟随重定向。Workers 不提供旧本地 Python 环境对内网 HTTP 接收器的访问能力。自定义 direct 禁止私密认证 Header；浏览器只能得到已验证公开目标和必要的短期凭据，绝不会得到服务端 API Key。

Relay 通过 `waitUntil` 在响应后发送。D1 条件事务限制活动转发槽位最多 128；短期 receipt 到期可回收，Worker 中断不会永久占满队列。外部发送仍是尽力交付，不是保证投递的业务消息队列。发送超时上限 5 秒；页面认证不等待发送完成。需要强投递保证时应独立评估 Cloudflare Queues 的费用与数据保留，不能把设备遥测当业务事实来源。

统计记录 attempted／delivered／failed／dropped／queued 和最近状态，不输出包含密钥的外部错误。直连目标令牌失败后也不会恢复可重放状态；需要重试时获取新的页面策略令牌。

## 保留与验证

事件保留期可设 1–365 天，每日定时清理。管理端可单独清除登录历史、审计或遥测，并留下维护事件。CSV 使用 UTF-8 BOM，防止表格公式注入，不含认证凭据。

测试覆盖 OFF 的查询短路、策略变更、一次消费、并发、载荷限制、URL／Header 验证和外部请求失败。实际第三方 Jason 服务的网络配对依赖其可用性；本仓库的契约测试不代表某个外部实例当前在线。
